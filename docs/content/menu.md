# Sayt navigatsiya menyusi (Navigation Menu)

Menyu tuzilmasi (uz va kaa tillarida). Maksimal 2 daraja, asosiy menyuda 7 ta bo'lim.

---

### Asosiy menyu (Header Menu)

1. **Bosh sahifa**
   - Nomi (uz): Bosh sahifa
   - Nomi (kaa): Bas bet
   - Havola: `/[locale]`

2. **Maqolalar** (Drop-down / Submenu bilan)
   - Nomi (uz): Maqolalar
   - Nomi (kaa): Maqalalar
   - Havola: `/[locale]/maqolalar`
   - Kichik bo'limlar (kategoriyalar):
     - Siyosiy tarix (`/[locale]/kategoriya/siyosiy-tarix`) / uz: Siyosiy tarix, kaa: Siyasiy tariyx
     - Madaniyat va san'at (`/[locale]/kategoriya/madaniyat-va-sanat`) / uz: Madaniyat va san'at, kaa: Mádeniyat hám kórkem óner
     - Arxeologiya (`/[locale]/kategoriya/arxeologiya`) / uz: Arxeologiya, kaa: Arxeologiya
     - Shaxslar hayoti (`/[locale]/kategoriya/shaxslar-hayoti`) / uz: Shaxslar hayoti, kaa: Tariyxıy shaxslar ómiri
     - Shaharlar tarixi (`/[locale]/kategoriya/shaharlar-tarixi`) / uz: Shaharlar tarixi, kaa: Qalalar tariyxı

3. **Davrlar**
   - Nomi (uz): Davrlar
   - Nomi (kaa): Dáwirler
   - Havola: `/[locale]/davrlar`

4. **Xronologiya**
   - Nomi (uz): Xronologiya
   - Nomi (kaa): Xronologiya
   - Havola: `/[locale]/xronologiya`

5. **Shaxslar**
   - Nomi (uz): Shaxslar
   - Nomi (kaa): Shaxslar
   - Havola: `/[locale]/shaxslar`

6. **Arxiv** (Drop-down / Submenu bilan)
   - Nomi (uz): Media arxiv
   - Nomi (kaa): Media arxiv
   - Havola: `/[locale]/arxiv`
   - Kichik bo'limlar (turlar):
     - Fotosuratlar (`/[locale]/arxiv?type=photo`) / uz: Fotosuratlar, kaa: Fotosúwretler
     - Tarixiy hujjatlar (`/[locale]/arxiv?type=document`) / uz: Hujjatlar, kaa: Hújjetler
     - Tarixiy xaritalar (`/[locale]/arxiv?type=map`) / uz: Tarixiy xaritalar, kaa: Tariyxıy kartalar
     - Qo'lyozmalar (`/[locale]/arxiv?type=manuscript`) / uz: Qo'lyozmalar, kaa: Qoljazbalar

7. **Xarita**
   - Nomi (uz): Interaktiv xarita
   - Nomi (kaa): Interaktiv karta
   - Havola: `/[locale]/xarita`

---
